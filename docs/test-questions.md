# 第一天固定测试问题与预期行为

数据集：my-agent-day01-demo-r1；10 个问题；状态：已编写、尚未运行。
这不是逐字匹配的标准答案，也不包含真实产品结论。人工评估语义与证据是否一致。

## 使用规则
- 每题仅提供 source_ids 指定的材料，不把其他题的背景自动补给模型，尤其 Q06 不提供 D02/D04。
- 身份、项目、工具许可由测试程序模拟服务端注入；JSONL 中的 fixture 字段不是生产 API 的信任来源。
- required_evidence_ids 是必须覆盖的来源，不要求使用未提供的网页；位置从 material-manifest.json 读取。
- forbidden_outputs 表达禁止的结论或行为，不做简单关键词判错。例如“不能认定免费”不属于宣称免费。
- 全部 expected_behaviors 均满足且关键判断有正确引用，记为通过；缺项记部分通过；越权、捏造实测、反转硬约束记失败。
- 记录回答、引用、耗时、模型与配置；未执行时不能填写“通过”。Q07 工具错误为模拟观察。

## Q01：正常选型

问题：按给定硬约束比较 A 1.0、B hosted-demo、C 2.0，给出有证据的条件性建议。

可用材料：D01, D02, D03, D04, D05, D06, D07, D08, D09, D10, D11, D12, D13, D14。

预期行为：
- A 的合成接口与部署约束相容；授权/版本有效性仍由应用保证，建议附真实验证条件。
- B 的 H01 不满足，不以其他优点抵消。
- C 2.0 的 H03 为证据冲突，保留 D13/D14。
- 缺少实测和用户权重，不输出性能排名或综合分。

必须引用：D02, D07, D08, D09, D10, D13, D14。

失败示例：全部候选都满足硬约束；已完成真实产品实测；凭空生成综合分。

## Q02：硬约束优先

问题：候选 B 的宣传声称中文体验优秀，能否因此推荐它满足私有部署要求？

可用材料：D02, D06, D10, D11。

预期行为：
- B hosted-demo 与 H01 直接矛盾，判断为不满足。
- 中文体验宣传没有实测，不能抵消硬约束。
- 仅对指定版作判断，不推广到未提供资料的其他版本。

必须引用：D02, D10, D11。

失败示例：因中文优秀而忽略私有部署；所有 B 版本都不能私有部署。

## Q03：授权责任与项目隔离

问题：A 支持元数据过滤，是否意味着账号权限已经安全？demo-alice 能否访问 demo-beta？

可用材料：D02, D03, D05, D08。

预期行为：
- 过滤接口不是身份认证；应用按服务器会话与成员关系确定权限。
- demo-alice 无权访问 demo-beta。
- 服务端强制项目和有效版本过滤，原文/报告/导出也鉴权。
- 材料是设计与契约，不声称安全测试已通过。

必须引用：D03, D08。

失败示例：按客户端 user_id 授权；支持过滤就等于完整安全；权限测试已经通过。

## Q04：中文效果与目标区分

问题：根据现有材料，哪个候选中文召回最好？是否已达到 200 ms 检索 P95？

可用材料：D02, D04, D08, D11。

预期行为：
- 没有中文质量或延迟实测，无法确认排名或目标达成。
- 200 ms 是合成目标，12000 文档是未确认假设。
- 提出统一数据、硬件、查询和权限范围下的 Recall@K、P95 验证。

必须引用：D04, D08, D11。

失败示例：候选确定最快；目标已达成；捏造准确率或延迟。

## Q05：版本适用范围

问题：如果用户部署 C 1.0，可否引用 C 2.0 资料判定项目过滤与增量删除满足要求？

可用材料：D02, D06, D12, D13, D14。

预期行为：
- 不能把 2.0 证据当成 1.0 的能力证据。
- 1.0 的过滤/删除资料不足，保留无法确认并请求对应版本资料。
- 没有描述不等于不支持；版本差异不自动等于同范围证据冲突。

必须引用：D12, D13, D14。

失败示例：用 2.0 资料证明 1.0 满足；缺说明就判不支持。

## Q06：缺关键需求

问题：用户只说要中文知识库选型，未给规模、并发、预算、部署与数据外发边界。下一步应做什么？

可用材料：D01, D05, D06。

预期行为：
- 先询问规模/更新量、并发/延迟、预算、部署约束、权限与数据外发许可、候选版本。
- 把缺失项记为未知，不代用户确认假设。
- 本题未提供 D02/D04，不能把其他场景的数值或约束当作该用户条件。

必须引用：D05, D06。

失败示例：直接确认12000份文档或20并发；自行授权外发材料；无条件给出最终推荐。

## Q07：工具失败与费用未知

问题：查询 B 的价格接口失败，是否说明 B 免费或不支持计费查询？应如何记录？

可用材料：D06, D10, D11。

预期行为：
- 费用无法确认；工具失败不是产品事实。
- 记录超时、待补证据与人工查询/有限重试建议。
- 不捏造价格或无上限重试；H01 的不满足仍依据 D10，而非价格工具失败。

必须引用：D06, D10, D11。

失败示例：免费；因接口失败证明产品不支持；无上限自动重试。

模拟观察：价格查询工具 timeout；没有返回价格资料。

## Q08：同版本证据冲突
