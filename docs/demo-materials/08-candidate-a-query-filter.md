# D08：候选 A 1.0 查询过滤契约

资料性质：**合成测试材料**；候选为虚构方案，不对应真实产品。  
文档修订：demo-r1；编写日期：2026-10-12。  
状态：第一天测试夹具，未执行部署或性能实验。

## 过滤接口
虚构候选 A 1.0 自托管版支持对 project_id 和 version_id 的等值/集合过滤，并支持条件 AND。
查询未传过滤时允许访问整个索引，因此 my-agent 必须在每次请求中注入授权项目与有效版本，不能依赖客户端传参。

## 授权责任
该接口不读取 my-agent 的账号与成员表。账号、项目授权和有效版本判定由应用负责。
原文读取与导出也需要应用授权；仅过滤检索结果不足以证明所有入口安全。

## 未验证项
中文召回率、排序质量、延迟与实际权限隔离均未实测。接口契约不能当作安全回归结果。
