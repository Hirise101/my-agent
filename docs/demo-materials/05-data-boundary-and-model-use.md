## 允许的数据
第一天材料均为合成测试数据。开发演示只使用公开资料或明确标注的合成资料。
真实企业文档、个人信息与真实凭据不属于这批演示数据，也未获得上传外部模型或搜索服务的许可。

## 内部与联网模式
默认 allow_web_search=false；内部模式不得调用公开搜索或网页抓取工具。
后续开启联网研究时，只查询用户允许的官方来源；不得把内部原文、项目名称、内部架构细节直接放进搜索词。
检索私有部署与模型是否采用外部 API 是两个配置问题。H01 不自动授权向任何模型提供方发送企业数据。
