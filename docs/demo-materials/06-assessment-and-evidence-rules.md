# D06：判断状态与引用规则

资料性质：**合成测试材料**；候选为虚构方案，不对应真实产品。  
文档修订：demo-r1；编写日期：2026-10-12。  
状态：第一天测试夹具，未执行部署或性能实验。

## 判断状态
- 满足：在同一候选、版本、部署模式下，有直接证据支持指定能力；演示材料仅说明合成契约，不证明真实产品已验收。
- 不满足：同一适用范围的资料明确说明与硬约束相违背。
- 无法确认：材料缺失、版本未知、适用范围不明或工具执行失败，且没有充分可用证据。
- 证据冲突：同一候选、版本和部署模式存在相反描述；同时保留双方引用，提出澄清动作。

## 排除与建议
先处理硬约束。B 即使声称体验良好，也不能抵消 D10 中仅托管部署与 H01 的直接冲突。
A 的合成接口与 H01/H02/H03 相容，建议必须附带应用授权、版本发布和真实 PoC 的验证条件。
C 2.0 的删除能力在 D13/D14 中存在冲突，解决前不能把 H03 标为已满足。无用户确认权重，不输出综合分。

## 引用与结果
关键判断引用实际读取的 Dxx 和章节/行号，保留产品版本。不得虚构页码、URL、来源 ID 或实验成绩。
不同版本的差异应先解释适用范围；只有范围重叠的相反描述才标记证据冲突。
测试夹具中给出的身份和 source_ids 由测试程序控制，不可直接用作生产 API 的授权依据。
