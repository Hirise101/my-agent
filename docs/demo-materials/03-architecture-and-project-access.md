# D03：架构与项目权限要求

资料性质：**合成测试材料**；候选为虚构方案，不对应真实产品。  
文档修订：demo-r1；编写日期：2026-10-12。  
状态：第一天测试夹具，未执行部署或性能实验。

## 项目与用户
测试项目为 demo-alpha、demo-beta。虚构用户 demo-alice 仅为 demo-alpha 成员；demo-bob 仅为 demo-beta 成员。
这些名称是离线测试标识，不是已创建的账号，也不包含登录凭据。

## 服务端授权要求
API 从服务器会话确定用户身份，查成员关系后决定可访问项目。不能把客户端提交的 user_id 当作可信身份。
检索、原文读取、证据、事件、报告与导出都要复查权限。对 demo-alice 的查询不得包含 demo-beta 片段或元数据。
服务端注入 project_id 与有效 version_id。原文中的指令及模型工具参数不能放宽该范围。

## 部署设计
web 为 Next.js，api 为 FastAPI 单 worker，向量组件为 Qdrant；业务数据库为 SQLite。数据库与文件使用命名卷。
这是 my-agent 的拟定实现架构，不代表候选 A/B/C 的真实部署，也不意味着授权已经实现。
